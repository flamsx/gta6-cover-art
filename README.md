# Golden Coast Cover Studio v2

A GTA-style cover art maker: turn your photos into multi-panel Vice City poster art — bold gradient lettering, a script subtitle, a uniform colour grade over every photo, and PNG export in the common post sizes.

Built for the [Make GTA 6 Cover Art](https://make.fun/bounty/gta6-cover-art-01) bounty on make.fun.

## What it does

- 7 layouts: Hero, Comic, 9-Panel, 1/2/3/4 panels
- 7 colour grades (Vice Sunset, Neon Night, Poster Ink, Golden Hour, Vice Mint, Bubblegum, Noir) — every panel photo is rendered *through* the grade: duotone gradient map, halftone dots, contrast/saturation, posterize, grain and an outline
- Crop and position each photo (drag, scroll to zoom, double-click to reset); fill all panels or spread photos
- Caption: title, subtitle, tagline, quote; undo/redo
- Export PNG in 1080 x 1080, 1080 x 1350 and 1920 x 1080, or all three at once

## Run it

Serve `app/` with any static server and open `index.html` — it works fully offline. Fonts (Anton + Pacifico, SIL OFL) and the six sample photos are bundled under `app/`.
